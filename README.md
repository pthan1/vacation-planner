# Out of Office

A local-first vacation accrual planner built with React and Vite.

## Run it

```bash
npm install
npm run dev
```

Open the URL shown by Vite (normally `http://localhost:5173`).

## Features

- Adjustable balance, accrual cycle, cap, workday, and reserve goal
- Time-off planner with automatic recalculation
- Balance forecast with cap and trip markers
- Forecasted forfeiture and reserve-gap warnings
- Automatic browser storage

## Checks

```bash
npm test
npm run build
```
